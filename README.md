# PromptCraft AI Studio (Cortex System & AI Intelligence Hub)

PromptCraft AI Studio là nền tảng kiểm định, phân tích và tối ưu hóa System Prompt AI theo chuẩn Anti-Slop, tích hợp trợ lý Cortex Bot, bộ công cụ phân tích Heuristic đa chiều, kho mã nguồn mở AI toàn cầu và hệ thống bảo mật Enclave Zero-Trust.

---

## 🌟 Tính Năng Cốt Lõi

1. **AI Prompt Inspector (Heuristic 6D)**: Rà soát cấu trúc R-C-O-C (Role, Context, Objective, Constraints), đo độ đa dạng từ vựng (Burstiness/Lexical Diversity), phát hiện từ mơ hồ gây ảo giác (Hallucination & AI Slop) và kiểm định bảo mật Prompt Injection.
2. **Cortex AI Assistant Pro**: Trợ lý AI hội thoại đa chế độ, hiển thị chuỗi suy luận Chain-of-Thought (CoT) trực quan, tự động đồng bộ Edge Storage tránh tràn bộ nhớ.
3. **Research Docs & Interactive Hub**: Kho tài liệu nghiên cứu chuyên sâu về Prompt Thấu Cảm và cơ chế RLHF, hỗ trợ đọc trực tiếp, tải về (.md) và nạp file tùy biến từ máy tính.
4. **Global AI Open Source Hub**: Tích hợp danh mục 50+ repository AI mã nguồn mở hàng đầu thế giới (Gemini SDKs, AI Agents, Prompting Frameworks, Open-Weight LLMs).
5. **Security Enclave & Admin Portal**: Cơ chế phòng thủ Anti-IDOR (Masked Hash IDs), bảo vệ Google reCAPTCHA v3 và cấp chứng chỉ Kỹ sư Kiểm định.
6. **Anti-Slop Single-Surface UI**: Thiết kế giao diện phẳng, tối giản, triệt tiêu card-lồng-card, không rung lắc/nảy khi tương tác.

---

## 🚀 Khởi Chạy Dự Án

### Yêu Cầu Môi Trường
- Node.js >= 18.0.0
- npm hoặc pnpm / yarn

### Cài Đặt & Chạy Môi Trường Phát Triển

```bash
# 1. Cài đặt các gói phụ thuộc
npm install

# 2. Khởi chạy Express Security Backend
node server.js

# 3. Khởi chạy Vite Frontend (Port 5173)
npm run dev
```
